## Takeways:

Validating a palindrome itself with two pointers is simple, but to understand the trick to this problem I had to figure out that when we run into the first mismatch, we have to check if the string can be a palindrome in 2 separate cases: (1) if we delete the current left index, moving onto l+1, r (2) or if we delete the current right index, moving onto l, r-1. We could use the basic valid-palindrome function as a helper to perform both of these checks conditionally on the first mismatch, and to return False for the whole thing if it's not palindrome after either possible first deletion.\
The space would be O(1) since we are just using two pointers. The time would be O(N) since we traverse each character once in the two-pointer main loop. Even if we run into our first mismatch, and it's the worst case situation where the helper will run twice, each helper call is a linear two-pointer palindrome check which is O(N), meaning at worst we have an overall constant number of linear scans of the string and an overall linear O(N) time complexity.
